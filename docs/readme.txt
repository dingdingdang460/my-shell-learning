壁纸管家 v0.9.3（免安装）
==================================

怎么用
------
1. 双击 WallpaperManager.exe，不用安装，不写系统目录。
2. 壁纸库默认在 D:\Wallpaper，目录结构：
     images\   静态壁纸
     videos\   动态壁纸（mp4）
     thumbs\   缩略图（自动生成）
     index.json
   第一次用可以随便放几张图进 images\，程序会自己扫出来；
   也可以把图片 / 文件夹 / 视频直接拖进窗口，会复制进库。
3. 主界面：左键点卡片 = 设为壁纸；右键 = 看大图 / 动态播放 / 删除；
   卡片右上角的 × 只有在鼠标移上去时才出现，防止手滑。
4. 搜索框：直接打字 = 搜本地库（支持拼音首字母，输入 cs 能搜到「城市」）；
   按回车 = 到网上找（中文搜 B 站图集，英文搜壁纸站，动态视频在结果条右侧切）。
5. 标题下面那行是筛选条，只有一档：
     类型：全部 / 视频 / 静态 / 有飘动视频
6. 关掉窗口不是退出，会缩到托盘继续定时轮换；托盘右键有完整菜单。
   全局快捷键：Ctrl+Alt+Space 暂停/继续，Ctrl+Alt+N 换下一张；F5 回上一张。

动态壁纸
--------
两种来源：
  - videos\ 里的 mp4：点卡片就直接铺到桌面
  - 静态图 + 云端生成的 3 秒飘动视频：右键「云端生成动效视频」
    点一下先弹出确认浮条：能选模型、看到大概花费和预计等待时间；
    点「开始生成」才提交，之后显示阶段（提交中 / 已接单 / 模型生成中 /
    下载中）、已等时长、预计还需多久，出片后自动下载、入库、换上桌面。
    没配好服务商 / API Key 时，任何一个生成入口都会先弹窗列明白缺什么
    （服务商、API Key、模型、两家单价），并给「去设置」；不会写工单、
    不会显示「生成中」、不会排队、不会扣费。
    出片只走云端图生视频模型：通义万相 DashScope（wan2.6-i2v-flash，
    720P 约 ¥0.15/秒）或火山方舟 Ark（Doubao-Seedance，约 ¥0.2~0.6/秒），
    本机脚本已停用。填好自己的 Key 才会真的提交请求。

  WorkBuddy 里免费的 Hy4 / Hy3 能用吗
    不能，也不是「下拉里少加两个模型」的问题：
      - 它们是 WorkBuddy 客户端的对话 / 推理模型（图片输入 + 思考模式），
        只能看图、写字，生成不了 mp4。官方说明「生成图片与视频会切换到
        相应多模态模型完成，按正常规则产生积分消耗」；限免只到
        2026-11-15 23:59，且每日有免费额度，触及后消耗积分。
      - WorkBuddy 的模型配置（内置 / 自定义）只供 WorkBuddy 自己转发对话，
        独立 exe 拿不到它的额度或 API Key。
      - 这里走的是「提交图 → 轮询异步任务 → 下载 mp4」的图生视频接口，
        和 /chat/completions 不是同一套协议，把 hy4 填进 model 只会报错。
    所以模型列表里只有两家的图生视频模型，绝不列 Hy4 / Hy3。

  出片通道（设置里可切，默认第一条）
    1) 优先 WorkBuddy 积分（默认）：点「云端生成」→ 先弹窗写明会消耗积分
       → 登记一张待领工单 + 把出片指令复制到剪贴板 → 卡片显示「⏳ 等 Buddy 出片」。
       粘到 WorkBuddy 会话（或等客户端自动领单）后，Buddy 用多模态模型图生视频，
       把 mp4 放进 videos\<id>.mp4，程序自动收货、自动换上桌面。
       不花服务商的钱；视频生成会消耗 WorkBuddy 积分（不是 Hy4/Hy3 对话免费额度），
       指令里要求 Buddy 先报积分、等你确认再生成。
       登记工单这一步不提交、不扣积分、不发请求、不改壁纸库文件，
       也不写按秒付费那条 queue 工单（不会误扣现金）。
       右键「查看 WorkBuddy 待领工单」能直接打开工单目录；片子没到货时
       再点「云端生成」会重新给指令，不会重复登记、不会重复扣积分。
    2) 服务商 API Key（按秒付费）：切到这项并填自己的百炼 / 方舟 Key，
       走原来的确认浮条 → 直连 → 轮询 → 下载，费用与预计等待都写在浮条上。
    右键「⧉ 复制交给 WorkBuddy 的指令（不填 Key）」是第 1 条的手动补充入口，
    只复制文字；「重新生成一片」同样优先走积分通道，会先提醒再消耗一次积分。

  不打开 WorkBuddy 也能出片吗
    - 用 WorkBuddy 积分：**不能**。积分绑定 WorkBuddy 客户端会话，自动领单是
      客户端里的定时任务，桌面 exe 拿不到会话凭证，也没法自己扣积分。
      客户端没开时，待领工单会一直留着（不自动出片、不扣积分），
      等客户端打开 / 你把复制的指令粘进会话才会出片。
    - 完全离线（不打开 WorkBuddy）：**能，但只能走按秒付费**。
      设置 →「出片通道」→「服务商 API Key」→ 填自己的阿里云百炼 / 火山方舟 Key，
      程序自己直连「提交图 → 轮询 → 下载 mp4」，不依赖 WorkBuddy、不消耗积分，
      费用按服务商公开单价（最便宜 wan2.6-i2v-flash 720P 约 ¥0.45 / 3 秒）。
      这条链路是应用内直连，不需要 Python、不需要外部脚本。
    - 没有第三条路：除非 WorkBuddy 将来提供可供外部程序调用的视频生成 API
      或可导出的凭证，否则积分无法在客户端之外使用。

  工单在哪看
    云端浮条上有「查看工单」按钮，点一下直接打开工单目录并选中这张单；
    工单是纯文本 JSON，可以自己看、自己改、自己删：
      %APPDATA%\wallpaper\jobs\queue\   等待中的单
      %APPDATA%\wallpaper\jobs\done\    已出片
      %APPDATA%\wallpaper\jobs\fail\    失败
    旧版本留下的、没配 API 的单会明确显示「待人工处理」，不会冒充「生成中」。

  「已经有片子就绝不重新花钱生成」
    只要壁纸库里存在跟这张图相关的视频，程序就直接用它播放，
    所有「云端生成」入口（右键菜单 / 预览按钮 / 顶栏 / 重试）都会被拦下：
    不弹下单浮条、不写工单、不向服务商发请求。认得的摆法包括：
      · videos\<id>.mp4                        规范主文件
      · videos\<id>.mp4.bak / .bak-v2          重出旧片留下的备份
      · videos\<id>.raw.mp4、<id>-v2.mp4 等     任何以图名开头的变体
      · videos\_raw\、videos\<id>\ 等子文件夹 里面跟图同名（或整个文件夹以图命名）的片子
      · images\、thumbs\、图片自己所在文件夹里 跟图片同名的 mp4
      · 云端工单里 out 字段指向、且还在库内的片子
      · 名字跟图片完全对不上的散片 —— 只有画面确实是同一张图才认
    前六种找到但不在规范位置时，会复制一份到 videos\<id>.mp4
    （原文件保留，日志写明来源）。

    最后一种按画面判定，不按名字猜，也不按时间「就近认领」：
    程序用系统自带的 Media Foundation 抽视频第一帧，和库里每张图片都缩到
    33x32 灰度，算归一化平均差（MAD）+ 64 位感知哈希（dHash），
    两个都达标才算「同一张背景」；全库按距离从小到大一对一分配，
    一段片子只归一张图、一张图只拿一段片子。
    例如库里那三段 Anime_..._<UTC 时间戳>.mp4，会各自归回真正对应的那张动漫图；
    刚下载、画面不同的新图绝不会被塞上别人的片子，点「动态」也不会播错。
    命中后直接播原文件，不复制、不改名、不往壁纸库写任何东西；
    日志写明用的是哪一段、MAD / hash 距离多少。
    阈值用真实库标定：同一画面 MAD 0.067~0.256、hash 6~12，
    不同画面 MAD ≥ 0.781，中间留了很宽的安全带（--contenttest 可复查）。

    想换一片：右键「✦ 重新生成一片（会重新计费）」或看大图时的第三个按钮，
    会先弹确认说清会再花一次钱，再走完整下单流程；旧片留一份
    .bak-regen-* 备份，新片到货自动换上。没配好服务商 / API Key 照样弹窗
    说明缺什么，不会假装「生成中」。
    菜单在有片时显示「云端动效：播放这段视频」，同时保留上面的重出通道；
    筛选条「类型 → 有飘动视频」也按同一套判定，不会把没有片子的新图算进去。
    取消订单时也不会再误把已经能动的状态清回静态。

桌面层用「Progman 分层子窗口 + GDI 直画」，图标可点、不被遮挡；
全屏游戏/放映时自动暂停，退出全屏恢复。托盘 → 动态壁纸 可以暂停、停止、查状态。

  切换壁纸后不会再留「▶ 播放中」
    卡片左上角的角标现在跟着真实状态走：切到静态壁纸、停止动态、删除当前
    壁纸、或换过去的那张片子启动失败，上一张的「▶ 播放中」都会立刻清掉，
    托盘和状态栏也一起改口；换成另一张动态时角标跟着移到新卡片上。
    判定除了看动态开关，还要求播放器进程真的活着 —— 就算配置万一残留，
    进程已经没了也不会再显示假的播放中（看门狗每 4 秒还会再对一次齐）。
    播放器窗口如果没能挂上桌面，会如实报「启动失败」并停干净，
    不会一边显示播放中、一边桌面其实什么都没动。

  点卡片切换壁纸时会自动播放已有的动态视频（v0.9.3）
    只要这张图标了「动态播放」、库里也确实找得到它的片子，点卡片就会直接
    交给播放器，不会只铺一张不动的静态图。以前载入索引时有一道旧闸只认
    videos\<id>.mp4：靠画面判定认领散片、没有规范主文件的图（例如库里
    biliart-17714251-4）会被一载入就清成静态，于是角标显示「有飘动」、
    点下去却只换静态壁纸。现在载入和切换用的是同一套七层发现规则，
    变体命名片、备份、子目录、工单 out、按画面认领的散片都算数。
    载入索引保持纯只读：只判断有没有片，不复制、不改名、不写壁纸库。
    真的找不到任何片子的图仍然会退回静态，不会假装能播、更不会自动下单。
    顺带把 --*test 自检跟真实桌面隔开：自检进程不再继承「上次动态壁纸」
    自动开播，不会碰你正在播的画面，也不会互相残留播放器进程。

设置
----
主界面右上角「设置」，可以改：
  - 壁纸库目录（换盘、换路径都行，改完自动重扫）
  - 定时轮换间隔 / 开关
  - 开机自启（写 HKCU 的 Run 键，不需要管理员，随时能关）
  - 开机播 / 解锁播欢迎动画
    （每张壁纸有自己的欢迎语；新下载/新入库的会自动生成一句，
      存在 %APPDATA%\wallpaper\greetings-auto.json，删掉即重新生成）
  - B 站图集是否过滤竖版图
  - 动态壁纸帧率上限
  - 合成图缓存上限（可一键清理）
  - HTTP 代理（留空 = 直连，只影响本程序自己的联网）
  - 云端生成：服务商、API Key、模型（下拉里带单价与预计等待）、出片分辨率；
    面板实时显示「本次大概花费 / 预计等待」。价格按服务商公开单价估算，
    火山方舟按 token 折算，实际以账单为准（2026-11-13 核实）
  - 配置导出 / 导入（换电脑时带走一份 json 即可；导入会校验是不是本程序的配置，
    覆盖前留 config.json.bak，坏文件不会把设置清空）

配置文件与日志
--------------
%APPDATA%\wallpaper\config.json        配置
%APPDATA%\wallpaper\jobs\              云端出片工单（queue / done / fail）
%TEMP%\wallpaper-debug.log             当天日志（排查问题用）
%TEMP%\wallpaper-debug-YYYYMMDD.log    历史日志，自动保留 7 天

卸载
----
删掉整个文件夹即可。如果开过开机自启，先在设置里取消勾选。
