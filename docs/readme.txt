壁纸管家 v0.4（免安装）
==================================

怎么用
------
1. 双击 WallpaperManager.exe，不用安装，不写系统目录。
2. 壁纸库默认在 D:\Wallpaper，目录结构：
     images\   静态壁纸
     videos\   动态壁纸（mp4）
     thumbs\   缩略图（自动生成）
     index.json
   第一次用可以随便放几张图进 images\，程序会自己扫出来；
   也可以把图片 / 文件夹 / 视频直接拖进窗口，会复制进库。
3. 主界面：左键点卡片 = 设为壁纸；右键 = 看大图 / 动态播放 / 删除；
   卡片右上角的 × 只有在鼠标移上去时才出现，防止手滑。
4. 搜索框：直接打字 = 搜本地库（支持拼音首字母，输入 cs 能搜到「城市」）；
   按回车 = 到网上找（中文搜 B 站图集，英文搜壁纸站，动态视频在结果条右侧切）。
5. 标题下面那行是筛选条，只有一档：
     类型：全部 / 视频 / 静态 / 有飘动视频
6. 关掉窗口不是退出，会缩到托盘继续定时轮换；托盘右键有完整菜单。
   全局快捷键：Ctrl+Alt+Space 暂停/继续，Ctrl+Alt+N 换下一张；F5 回上一张。

动态壁纸
--------
两种来源：
  - videos\ 里的 mp4：点卡片就直接铺到桌面
  - 静态图 + 云端生成的 3 秒飘动视频：右键「云端生成动效视频」
    点一下先弹出确认浮条：能选模型、看到大概花费和预计等待时间；
    点「开始生成」才提交，之后显示阶段（提交中 / 已接单 / 模型生成中 /
    下载中）、已等时长、预计还需多久，出片后自动下载、入库、换上桌面。
    没填 API Key 时浮条直接提示「去设置」，不会排队、不会假装在生成。
    出片只走云端图生视频模型（通义万相 / 火山方舟），本机脚本已停用。
桌面层用「Progman 分层子窗口 + GDI 直画」，图标可点、不被遮挡；
全屏游戏/放映时自动暂停，退出全屏恢复。托盘 → 动态壁纸 可以暂停、停止、查状态。

设置
----
主界面右上角「设置」，可以改：
  - 壁纸库目录（换盘、换路径都行，改完自动重扫）
  - 定时轮换间隔 / 开关
  - 开机自启（写 HKCU 的 Run 键，不需要管理员，随时能关）
  - 开机播 / 解锁播欢迎动画
    （每张壁纸有自己的欢迎语；新下载/新入库的会自动生成一句，
      存在 %APPDATA%\wallpaper\greetings-auto.json，删掉即重新生成）
  - B 站图集是否过滤竖版图
  - 动态壁纸帧率上限
  - 合成图缓存上限（可一键清理）
  - HTTP 代理（留空 = 直连，只影响本程序自己的联网）
  - 云端生成：服务商、API Key、模型（下拉里带单价与预计等待）、出片分辨率；
    面板实时显示「本次大概花费 / 预计等待」。价格按服务商公开单价估算，
    火山方舟按 token 折算，实际以账单为准（2026-11-13 核实）
  - 配置导出 / 导入（换电脑时带走一份 json 即可）

配置文件与日志
--------------
%APPDATA%\wallpaper\config.json        配置
%APPDATA%\wallpaper\jobs\              云端出片工单（queue / done / fail）
%TEMP%\wallpaper-debug.log             当天日志（排查问题用）
%TEMP%\wallpaper-debug-YYYYMMDD.log    历史日志，自动保留 7 天

卸载
----
删掉整个文件夹即可。如果开过开机自启，先在设置里取消勾选。
