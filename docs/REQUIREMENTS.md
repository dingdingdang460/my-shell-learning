## 1. 产品定位

**一句话**：一台**离线优先**的笔记本动态壁纸管家 —— 壁纸先落到本地，开机没网也照常换、照常播。

**三个真实场景**

1. **早上开机**：没有 Wi-Fi 也能立刻用上昨天的壁纸；屏幕亮起后有一小段欢迎动画，2.5 秒自己退场，不挡操作。
2. **白天工作**：桌面在几组「城市夜景 / 雨夜 / 抽象」之间慢慢轮换，全屏打游戏或看视频时自动暂停，不吃帧、不发烫。
3. **合盖再开**：解锁后壁纸立刻续播，不用等它重新加载。

**明确不做（防范围膨胀）**

- 不做账号体系、不做云同步、不做壁纸商店
- 不做多显示器独立设置
- 不做 Wallpaper Engine 创意工坊解析（工坊文件加密，只有 WE 自己能播）
- 不把第三方站点的自动抓取做成常驻后台任务（站点一改版就废，且不稳定）

## 2. 已确认需求（来自对话，附实测依据）

| 决策项 | 结论 | 依据 |
|---|---|---|
| 技术形态 | Tauri + 前端 | 装完 8–12MB，内存占用低，符合「轻量化」 |
| 显示器 | 只要主屏 1920×1080 | 本机实测分辨率 |
| 图源-动态 | **motionbgs.com** 为主（分类浏览 + 站内搜索） | 实测：sitemap 9968 条、1080P 直链约 10MB、4K 约 21MB、无 Key 无防盗链、下载 1MB/s；站内搜索 `/search?q=neon city` 实测返回 7 条真实结果 |
| 图源-静态 | motionbgs 的 4K 封面图（同源同风格）+ 本地导入 | 实测 `media/<id>/<slug>.3840x2160.jpg` 直链可用，单张约 2MB |
| 图源-静态（降级） | 360 壁纸 **仅分类接口可用** | 实测：`getAllCategoriesV2` 返回 18 类正常；`getWallPaperListV2`、`searchWallPaper` 均返回 200 但 0 字节，不可用作内容源 |
| 已排除 | Wallhaven（超时）、极简壁纸 API（返回 500）、mylivewallpapers（跳转拦截）、desktophut（超时）、wallpaperwaifu（一次性 token，97MB/张）、彼岸图网（反爬，返回 1.9KB 壳页）、api.vvhan（不可达） | 见实测记录 |
| 动态壁纸 | 真桌面层（WorkerW 注入），非全屏置顶 | 主人选定 |
| 欢迎动画 | 开机登录 + 解锁都触发；粒子星光 + 文字 | 主人选定 |
| 素材画质 | 1080P 为准 | 屏幕原生 1920×1080，4K 属无收益解码开销；4K 直链已存索引，可单张升级 |

## 3. 功能需求（P0 = 首版必做）

### F1 壁纸库浏览
- 网格视图，卡片含缩略图、标题、标签、时长、体积、来源
- 分「全部 / 动态 / 静态 / 收藏」四个视图
- 顺序按入库先后（index.json 顺序）。~~支持按体积、时长排序~~ → 2026-11-13 主人决定不做手动排序，筛选条只留「类型」
- **验收**：17 张本地库在断网状态下全部能显示缩略图与信息，无破图

### F2 预览与一键设为壁纸
- 悬停/点击预览：动态壁纸在卡片内静音循环播放（限流：同屏最多 3 个在播）
- 「设为壁纸」单击生效，无需保存文件、无需进系统设置
- 静态：`SystemParametersInfoW(SPI_SETDESKWALLPAPER)`
- 动态：挂载到 WorkerW 层播放
- **验收**：点击后 1 秒内桌面壁纸变化；动态壁纸在桌面图标下方循环播放，图标可正常点击

### F3 搜索与筛选（本地）
- 关键词搜索（标题、标签、来源），走内存索引，不查磁盘
- 筛选：类型（动态/静态）、标签、分辨率、体积区间、时长区间、色系
- 支持拼音首字母（如 `cs` 命中「城市」）
- **验收**：1 万条库规模下输入关键词 100ms 内出结果

### F3b 联网搜索与在线浏览（P0，主人指定新增）
**这是新增模块，独立于本地库，是「进货渠道」。**

- 入口：主界面顶部搜索框 + 「在线」标签页；与本地搜索分开展示（避免混淆"我有的"和"网上有的"）
- 动态壁纸：`GET https://motionbgs.com/search?q=<关键词>` → 解析列表页内嵌的 `/media/<id>/<slug>.<分辨率>` 标识 → 还原缩略图 / 1080P / 4K / 4K 静态封面
- 分类浏览：按 tag 频道进（nature / space / city / abstract / fire / car / ocean / rain / anime / game …），点分类即拉该 tag 页
  - 动漫这块实测有货：`tag:anime` 返回 Frieren / Killua / 刀剑神域 / Re:Zero 等真实条目，可作 B 站之外的常规来源
- 结果卡信息：缩略图、标题、分类、可选形态（动态 mp4 / 静态 4K jpg）、体积
- 下载：动态存 `videos/`，静态存 `images/`，完成后写索引进本地库
- **无结果的处理**：站点对无匹配关键词不返回空列表，而是回一批推荐内容（实测 `zzzqqqxxx` 仍返回 4 条无关结果）。所以不能用「列表为空」判断，须比对标题与关键词，不匹配则提示「没搜到相关壁纸，下面是推荐」——把推荐也展示出来，别让用户面对空白
- **无网降级**：离线时搜索框置灰并提示「当前离线，仅显示本地库」，不弹错误框、不卡界面
- **限流与重试**：请求间隔 ≥ 800ms，单次失败重试 1 次（指数退避），连续 3 次失败停止并提示，不无限重试
- **验收**：断网搜索 → 提示文案正确且界面可用；有网搜「neon city」→ 出 7 条真实匹配（已实测：Seoul Night Street / Neon Light City / Neon City Snowing …）；点下载 → 落盘并出现在本地库

### F3c 可选第二图源（P1）
- 设置里可填 Pexels / Pixabay 的免费 API Key，填了即在在线页多一个源
- 没填就不显示该源，不报错、不打扰
- 理由：这两个源必须注册 Key，内置 Key 不合规也不稳定

### F4 下载与本地库
- 在线壁纸点「下载」→ 落盘 → 写入 `library/index.json` → 进本地库
- 断点续传、失败重试 2 次、失败给出明确原因（网络/空间/资源失效）
- 下载完成做完整性校验：字节数一致 + mp4 `ftyp` 头 + 时长可解析
- **验收**：断网时点下载给出「当前无网络」提示且不产生半截文件

### F5 收藏与历史
- 收藏（星标）独立于本地库：在线壁纸也可收藏，收藏记录含来源直链
- 切换历史：记录最近 50 次设为壁纸的操作，可一键回滚上一张
- **验收**：重启软件后收藏与历史仍在；回滚能把壁纸还原成上一张

### F6 定时轮换
- 间隔：30 分钟 / 1 小时 / 3 小时 / 每天固定时刻 / 每次开机
- 轮换池：全部 / 仅收藏 / 指定标签 / 指定文件夹
- 模式：顺序 / 随机不重复（一轮内不重复，一轮结束再洗牌）
- 切换动效：静态壁纸 300ms 交叉淡化（动态壁纸直接切）
- **验收**：设为每分钟轮换（调试模式）连续跑 10 次，无重复、无卡顿、内存不涨

### F7 动态壁纸播放（技术难点）
- 视频循环、静音、铺满、保持宽高比（多余部分裁切）
- 挂载在桌面图标下方（WorkerW 层），不遮挡图标、不影响右键菜单
- Explorer 重启后自动重挂（检测 WorkerW 失效）
- 帧率上限 30fps；解码优先走 GPU
- 失败降级：挂载失败时退回该视频首帧作静态壁纸，并托盘提示一次
- **验收**：设动态壁纸后按 `Win+D` 显示桌面正常、图标可点、任务管理器里进程 GPU 占用 < 15%

### F8 开机 / 解锁欢迎动画
- 触发：用户登录后一次 + 每次解锁后一次
- 表现：黑场淡入 → 星光粒子汇聚 → 文字「欢迎回来，主人」→ 2.5 秒后自动淡出
- 可跳过：点击任意处 / 按 Esc 立即结束
- 零联网：粒子与字体全部本地资源
- 不抢焦点：不阻塞键鼠，动画期间可正常操作
- **验收**：锁屏解锁后 3 秒内动画出现并在 2.5 秒内消失；连续解锁 3 次均正常；断网无差异

### F9 托盘与自启
- 托盘常驻：显示当前壁纸名、下一张、暂停轮换、打开主界面、退出
- 关窗口 = 最小化到托盘（可配置为真退出）
- 开机自启：写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`，延迟 8 秒启动避免和系统抢资源
- **验收**：重启电脑后托盘图标自动出现，壁纸自动续上

### F10 设置
- 壁纸库路径（可改到 D 盘）、缓存上限、轮换规则、动画开关、自启开关、代理
- 配置存 `%APPDATA%/wallpaper/config.json`，可一键导出/导入
- **验收**：改路径后重启，新路径生效且旧壁纸不丢

## 5. 动态壁纸技术方案

**层级原理**：Windows 桌面由 `Progman` 与 `WorkerW` 两个窗口构成，图标由 `SHELLDLL_DefView` 承载。把自建窗口 `SetParent` 到 `WorkerW`，就位于图标下方。

**实现路径（Rust 侧）**
1. 枚举顶层窗口找到 `WorkerW`（向 `Progman` 发 `0x052C` 触发拆分）
2. 创建无边框 Win32 子窗口，宿主 WebView2（`<video>` 播本地 mp4）
3. `SetParent(hwnd, workerw)` + 尺寸跟随显示器
4. 监听 Explorer 重启（`WM_` 与进程存活轮询双保险）→ 重新枚举并重挂

**播放器选型对比**

| 方案 | 功耗 | 开发成本 | 已知问题 |
|---|---|---|---|
| WebView2 + `<video>` | 中（多一层合成） | 低（前端即可控制） | 部分老显卡驱动在 WorkerW 下合成偶发黑屏 |
| 原生 Media Foundation | 低 | 高（C++/Rust 手写解码管线） | 需要处理 HDR、色彩空间 |

**决定**：先用 WebView2 打通（能快速验证效果），把暂停/降级策略做扎实；若实测 GPU 占用超 15% 或出现黑屏，再换 Media Foundation。这个取舍会写进 v0.2 验收，不靠猜。

**已知风险**
- **本机是 Windows 11 25H2（build 26200）**，24H2 之后桌面窗口层级做过调整，`0x052C` 触发 WorkerW 拆分的行为可能与本机不符 —— 这是全项目最大不确定项，因此在第 10 节前置了一个 Spike
- 动态壁纸运行时改系统「个性化→背景」会被覆盖，需监听并提示
- 锁屏/待机恢复后窗口可能失联，需重挂（S4 已覆盖）

## 6. 欢迎动画技术方案

**触发链路**
- 登录：写启动项，进程起来后直接放
- 解锁：主进程常驻，用 `WTSRegisterSessionNotification` 收 `WTS_SESSION_UNLOCK`；若失败，降级为轮询 `WTSQuerySessionInformation` 会话状态
- 兜底：监听系统日志 `Winlogon` 事件 4801（需读事件日志权限，仅作备选）

**动画规格**
- 全屏无边框、点击穿透（不抢焦点）
- 时间线：0–400ms 黑场淡入 → 400–1800ms 粒子汇聚 → 1200–2000ms 文字淡入 → 2000–2500ms 整体淡出
- 文字：**按当前壁纸的分类取主语**，格式固定「欢迎 + 主语」
  - 配置在 `resources/greetings.json`：3 个模板（`欢迎回来，{who}` / `欢迎，{who}` / `欢迎回家，{who}`）× 12 类主语池
  - 取词逻辑：读当前壁纸 tag → 经 `tag_map` 映射到主语池 → 随机取一句；分类未收录则用 `default` 池
  - 已按本地库实际分类验证：`abstract → 欢迎，走神的人`、`city → 欢迎，还没睡的城市居民`、`ocean → 欢迎，赶海的人`
  - 新增分类只需往 json 里加一组主语，不用改代码
- 跳过：点击 / Esc / 任意键
- 多显示器：只在主屏播放（当前单屏，预留）
- 性能：动画期间 CPU < 8%，结束后立刻释放渲染进程

**与壁纸的启动顺序**：先起动画（Explorer 可能还没就绪）→ 动画结束后再挂壁纸，避免壁纸闪烁。

## 7. 数据与目录结构

```
D:\Wallpaper\            # 壁纸库（已定，主人在 D 盘，816GB 可用）
├─ videos/               # 动态壁纸 mp4
├─ images/               # 静态壁纸
├─ thumbs/               # 缩略图 560px
└─ index.json            # 索引（已建立，字段如下）

%APPDATA%/wallpaper/
├─ config.json           # 用户配置
├─ state.json            # 当前壁纸、轮换游标、历史
└─ logs/                 # 滚动日志，保留 7 天
```

**index.json 单条字段**

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一标识（取来源 slug） |
| `title` | string | 标题 |
| `tag` | string | 来源分类 |
| `file` | string | 相对路径，如 `videos/xxx.mp4` |
| `thumb` | string | 缩略图相对路径 |
| `bytes` | number | 字节数（实测，非估算） |
| `duration_s` | number | 时长秒（mvhd 解析） |
| `src_res` | string | `1080p` / `2160p` |
| `upgrade_4k` | string | 4K 直链，供单张升级 |
| `added_at` | string | 加入时间 |

## 9. 测试计划

**自动化（写进仓库，可重复跑）**
- `mp4_duration` 解析单测：正常文件、截断文件、非 mp4 文件三类
- 索引读写单测：空库、重复入库、字段缺失
- 轮换算法单测：顺序、随机不重复、池为空时的降级
- 下载校验单测：字节数不符、ftyp 缺失 → 必须判失败

**手工验收（逐条打勾）**
1. 断网启动 → 本地库 17 张可浏览、可设壁纸
2. 设动态壁纸 → `Win+D` 显示桌面、图标可点、GPU < 15%
3. 锁屏解锁 3 次 → 动画均正常出现、2.5s 内消失、可 Esc 跳过
4. 拔电源 → 动态壁纸切静态；插回 → 恢复动态
5. 全屏打游戏 → 壁纸暂停；退出 → 恢复
6. Explorer 崩溃重启 → 壁纸自动重挂
7. 定时轮换跑 10 轮 → 无重复、内存不涨
8. 重启电脑 → 托盘自启、壁纸续上

## 12. 风险登记

| 风险 | 影响 | 应对 |
|---|---|---|
| WorkerW 注入在新版 Windows 失效 | 动态壁纸不可用 | 保留静态降级；跟进系统版本实测 |
