## 2. 构建 / 自检怎么跑

```bash
# 编译（--noboot：只编译替换，不启动 GUI、不抢桌面）
cmd //c "build.bat --noboot > build-run.log 2>&1" < /dev/null
#   build.log / build-player.log 都是 0 字节 = 零错误零警告

# 运行期日志
tail -80 "$TEMP/wallpaper-debug.log"

# 打包
cmd //c "package.bat > package-run.log 2>&1" < /dev/null
```

**两个坑**：bat 必须 CRLF 且**不能带 BOM**（BOM 会让 cmd 把 `\ufeff@echo` 当命令、
`@echo off` 失效、整份回显）；`.cs` 是 C# 5，别用 `$""` / `?.` / `nameof` / 表达式体成员。

自检开关（一次一个参数，GUI 常驻，跑完外部 kill）：
