## 11. 11-15：WorkBuddy 免费模型与云端生成的关系（v0.9.2）

主人问「选定模型不能用 WorkBuddy 里配的吗，hy4 和 hy3 都是免费的」。
结论：**不能**，不是少加两个下拉项；详见 `PROGRESS.md` 第十九节。

- Hy4 / Hy3 是 WorkBuddy 客户端的**对话 / 推理模型**（官方文档「内置模型」表：
  图片输入 + 思考模式），只能看图、写字，产出不了 mp4。官方公告写明
  「生成图片与视频会切换到相应多模态模型，按正常规则产生积分消耗」；
  限免到 2026-11-15 23:59，每日有免费额度，触及后消耗积分。
- WorkBuddy 的模型配置只供它自己转发对话（Key 存本地 `workbuddy/models.json`），
  独立 exe 拿不到其额度/凭证；本程序的 `GenApi` 是「提交图 → 轮询 → 下载 mp4」
  的异步图生视频接口，与 `/chat/completions` 不同协议，`model` 必须是图生视频 ID。
  所以 `GenModels` 里**没有也不会**加 hy4/hy3，避免「选了免费、点了没片」的假状态。
- 主人追加要求：「云端生成优先消耗 WorkBuddy 积分」「直接做成完整可用的功能，
  而不是只给我一个页面和点击之后没有任何反应的按钮」。
  因此**默认出片通道改成 WorkBuddy 积分**，按秒付费变成可选项：
  - 设置 →「出片通道」下拉，默认「优先 WorkBuddy 积分」；配置字段
    `AppConfig.GenChannel`（`buddy` / `api`），老配置缺字段自动回填 `buddy`。
  - 点「云端生成」（含「重新生成一片」）默认动作：弹窗告知积分 →
    在 `%APPDATA%\wallpaper\jobs\buddy\<id>.json` 登记**待领工单** →
    出片指令进剪贴板 → 卡片角标「⏳ 等 Buddy 出片」。
    三选：是 = 积分出片 / 否 = 改用按秒付费 / 取消 = 什么都不做；
    取消和改用付费都不登记工单。工单与 `jobs\queue` **分开**，

  - 右键「查看 WorkBuddy 待领工单」可打开目录；待领时再点生成只是重给指令，
