## 1. 本轮做了什么

1. **功耗守卫**（P1-4）：`app/PowerGuard.cs`。电池供电且电量 ≤ 阈值（默认 20%）

   后台线程写 `wallpaper-crash-*.log`。托盘新增「打开日志」。
3. **删除进回收站**（P1-6）：`app/Recycle.cs`，`SHFileOperation + FOF_ALLOWUNDO`；
   回收站不可用时才退回硬删。

   检出就 delogo 修补，复查干净才交付。接在 API 直连下载完成后、积分通道收货时。
5. **API 直连通道打通**（v0.9.5 第二个提交）：`audio:false` 免得按有声价扣钱、
   秒数按模型夹取免得参数被拒、402 余额不足给中文提示。

## 3.1 本轮 API 通道的硬结论（别改回去）

- 通义 `wan2.6-i2v-flash` 的 `audio` 默认 **true**（有声价是有声 = 无声的两倍），
  壁纸一律传 `false`。
- `wan2.2-i2v-flash` **固定 5 秒**，`duration` 传 3 会被服务端拒；
  所有下单与估价都走 `GenModels.ClampSeconds`。
- 价格显示、提交参数、账单三者必须用同一个「实际秒数」，别再各算各的。

## 3.2 角标验收的硬结论（别改回去）

- **判定只认「上下两条等长长横线 + 行距对」**，不认「横线长」单项：
  单看长度会被建筑边、亮边误伤（库里 `biliart-10096573-7` 有 22px 亮边、
  `floating-city-dreams` 有 36px 建筑边）。全库 24 个样本按这条规则零误报。
- **框按比例算，不写死像素**：`x=0.0074W-4, y=0.0130H-4, w=0.0612W+8, h=0.0495H+8`。
  写死 88×44 只在 1344×768 上准，1080P 会漏。
- **修补顺序不能省**：先备份 `.bak-wm` → 写 `.wm-tmp.mp4` → **再量一次** → 干净才换名。
  少这一步就等于「修了但没验」，回到 11-15 那个问题。
- **没 ffmpeg 不许说「干净」**：`Checked=false` 与 `Clean=false` 是两码事，
  界面必须说清「未验收」。片子要留着（花了钱）。
- **只对云端出的新片自动动手**。主人自己导入的视频一律不碰（托盘里显式点才改）。

## 4. 已知坑（新增）

- 跑 `--*test` 前先确认主程序没在运行，否则被单实例锁挡掉、**日志不写**，
  看着像「自检没跑」。跑前把 `TEMP`/`TMP` 指向仓库内 `.selftest-tmp\`。
- **凡是会走 `GenCloud` / `RegenCloud` 的自检，都必须把 `Config.GenChannel` 固定成
  `api` 并还原**。真实配置默认 `buddy`，不固定就会走进积分通道的确认框，
  轻则断言全错（`--cloudflowtest` 第 0 步「取消这单」），重则真弹窗卡死
  （`--clouddialogtest`）。本轮已经踩过两次。
- `--launchtest` 偶尔会因上一项自检的播放器残留报 FAIL；单独重跑即可，
  日志里「开播前没有残留播放器」为 √ 就说明是环境残留，不是代码问题。
- `--guardtest` 的回收站断言会把 2 个几十字节测试文件送进系统回收站
  （建在 `.selftest-tmp` 下），清空回收站即可。
- **`export TEMP=... TMP="$TEMP"` 是错的**：同一条 export 里的 `$TEMP` 展开的是**旧值**，
  结果 `TMP` 仍指向真实临时目录，而 .NET 的 `Path.GetTempPath()` 先读 `TMP` ——
  日志会跑到工作空间外。必须分两句写，或 `export TEMP=...; export TMP=...`。
  本轮踩过一次，日志落在真实 `%TEMP%\wallpaper-debug.log`（仅追加日志，无其它改动）。
- **自检断言名 / 输出里别出现 `×`**：所有 `--*test` 的判 PASS 逻辑是
  「detail 里不含 `×`」，一个「1344×768」就会让 18/18 全过却报 FAIL。
  尺寸统一写 ASCII 小写 `x`。
- **`--genapicheck` 已收进 `SelfTestArgs()` 闸门**（11-16 修）。以前它名字不以 `test`
  结尾，判不出来，于是照常恢复动态壁纸、拉起播放器，还顺手把真实库
  `D://Wallpaper//index.json` 的 mtime 改写掉（内容与 `.bak` 逐字节相同，但这就是
  「自检碰了工作空间外的文件」），同时保存了一次 `appdata\config.json`。
  现在跑它不动壁纸、不写库、不存配置。**以后新增任何 `--*` 检查项，务必确认
  名字以 `test` 结尾，或像它一样显式加进闸门。**
- 四个会写真实库/配置的自检（`--deltest / --greettest / --configtest /
  --arrivetest`）默认不跑；`--cloudtest` 会写死工单，永远别跑。
